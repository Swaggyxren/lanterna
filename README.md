# Lanterna

**Lanterna** is an Android app that hosts a Minecraft Java Edition server natively on your phone — no Termux, no proot, no root.

## Downloads

Pre-built APKs are published to the [Releases](https://github.com/Swaggyxren/lanterna/releases) tab.

- **Min Android version:** 8.0 (API 26)
- **Architectures:** arm64-v8a (most modern phones)
- **Java runtime:** *not bundled.* Lanterna lets you install your own JRE (Adoptium Temurin 8 / 17 / 21 / 25) inside the app.

## Issues & feedback

This repository hosts release artifacts only — the source is maintained privately. Please open an [Issue](https://github.com/Swaggyxren/lanterna/issues) for bug reports, feature requests, or release-related questions.
